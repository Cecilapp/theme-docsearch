# DocSearch for Cecil

This website is the demo of the [_DocSearch_ component theme](https://github.com/Cecilapp/theme-docsearch) for [Cecil](https://cecil.app).

Click the **Search** button in the header, or press `Ctrl`/`⌘` + `K`, then try a few queries, like `crawler` or `api key`.

This demo queries the public index of the [DocSearch documentation](https://docsearch.algolia.com): results link to that website.
