# DocSearch pour Cecil

Ce site est la démo du [composant de thème _DocSearch_](https://github.com/Cecilapp/theme-docsearch) pour [Cecil](https://cecil.app).

Cliquez sur le bouton **Rechercher** dans l’en-tête, ou appuyez sur `Ctrl`/`⌘` + `K`, puis essayez quelques requêtes, comme `crawler` ou `api key`.

Cette démo interroge l’index public de la [documentation de DocSearch](https://docsearch.algolia.com) : les résultats pointent vers ce site.

[Lire la documentation](docs/)
